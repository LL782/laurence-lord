## Lab notes

The experiment: [An interactive image montage using JS, CSS and HTML](/labs/LL782-poster/)

1. Follow the link above
1. Move you mouse or tap around
1. Enjoy the tilting and stretching

### Dev notes:

#### Theme 1: build in the browser

1. HTML and CSS rather Photoshop
1. Mask over JPG, CSS to pixel push
1. Screenshot at 1200 x 630px to generate `og:image`

#### Theme 2: 3D CSS

1. [CSS `perspective` attribute](https://developer.mozilla.org/en-US/docs/Web/CSS/perspective)
1. `translateX` not used but fun
1. Try`perspective-origin`, `rotateY` and `rotateX`

#### Theme 3: JS to set CSS vars

1. Lea Verou showed this years ago <Emoji label="starry-eyed">🤩</Emoji>
1. Track `mouseover` with JS
1. Update a [CSS custom-property](https://developer.mozilla.org/en-US/docs/Web/CSS/--*)
1. Write values 0-1 for simplicity
1. `calc()` to convert as needed
